# NUMPY, PANDAS, MATPLOTLIB AND SEABORN
A concise workbook covering foundational skills in using NumPy, Pandas, Matplotlib and Seaborn, the essential libraries for data manipulation in Python.
It aims to develop foundational skills in using NumPy, Pandas, Matplotlib, and Seaborn for data manipulation, analysis, and visualization. By exploring these libraries I've performed various operations on numerical and tabular data, as well as create insightful visualizations. It helped me gain hands-on experience with array operations, data handling, and data visualization techniques necessary for data analysis and machine learning.
