# SUPERVISED LEARNING
Supervised learning is a type of machine learning where an algorithm learns from labeled data. In this "supervised" process, the model is provided with input-output pairs (like an image of a cat paired with the label "cat") that act as a teacher, guiding the model to recognize patterns and make accurate predictions on new, unseen data.
Supervised learning tasks are generally divided into two categories based on the type of output they predict:

## Key Benefits and Challenges

- Benefits: High accuracy for well-defined tasks, traceability (it’s clear what the model was taught), and broad utility in industries like healthcare and finance.
- Challenges: Requires large amounts of accurately labeled data, which is often time-consuming and expensive to produce. It can also suffer from overfitting if the model learns the training data too specifically and fails on new data.
