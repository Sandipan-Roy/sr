# LINEAR REGRESSION
Linear regression is a supervised machine learning algorithm and statistical technique used to model the relationship between a continuous dependent variable (target) and one or more independent variables (predictors). It finds the best-fitting straight line (\(Y=aX+b\)) that minimizes the sum of squared residuals to predict future numerical outcomes.

The purpose of this is to create a concise workbook covering advanced skills in using NumPy, Pandas, Matplotlib, Seaborn and Linear Regression model uncovering insights, patterns, relationships within the data and predicting the target variable using Linear Regression model.

The repository consists of:
