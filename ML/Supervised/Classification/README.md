# CLASSIFICATION
Classification in machine learning is a supervised learning approach that sorts data into predefined categories or classes based on input features. It predicts discrete labels (e.g., Yes/No, Spam/Not Spam) rather than continuous values, training on labeled data to map inputs to specific categories.

## Key Aspects of Classification Analysis:

- **Supervised Learning:** The model learns from a training dataset that already contains the answers (labeled data).
- **Discrete Outputs:** Unlike regression, which predicts continuous numbers, classification predicts a categorical label.
- **Decision Boundaries:** Algorithms create a boundary to separate different classes in the feature space.

- **Types of Classification:** 
    - **Binary Classification:** Sorting data into one of two categories, such as spam or not spam.
    - **Multiclass Classification:** Categorizing data into more than two classes, such as classifying an image as a dog, cat, or horse.

## Key Concepts:

- **Least Squares:** A method to find the best-fitting line by minimizing the squared vertical distances between data points and the line.

- **P-value:** Determines if the relationship between variables is statistically significant; a \(p\)-value \(<0.05\) usually indicates a significant relationship.

- **Multicollinearity:** In multiple regression, this occurs when independent variables are highly correlated with each other, making it difficult to determine individual impact.
