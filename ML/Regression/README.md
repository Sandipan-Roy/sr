# REGRESSION
Regression analysis is a statistical technique that models the relationship between a dependent variable (target) and one or more independent variables (predictors) to predict continuous numerical outcomes. By finding the best-fitting line or curve, it identifies trends and quantifies how changes in features affect the outcome.

## Key Aspects of Regression Analysis:

- **Goal:** The primary goal is to predict outcomes, understand factor impacts, and forecast trends.

- **Types of Regression:** 
    - **Simple Linear Regression:** Models relationships with a straight line, minimizing the sum of squared errors between observed and predicted values.
    - **Multi-Linear Regression:** Uses two or more independent variables to predict a single outcome.
    - **Logistic Regression:** Used for predicting binary outcomes (e.g., success/failure) using a sigmoid curve.

- **Components:** Includes a dependent variable (\(Y\)), independent variables (\(X\)), slope (\(\beta \)), intercept (\(\alpha \)), and an error term (\(\epsilon \)).

- **Assumptions:** Requires data to follow specific patterns, including linearity, homogeneity of variance (constant error), normality, and independence of observations.

- **Applications:** Widely used in business forecasting, risk assessment, trend analysis, and economics.

## Key Concepts:

- **Least Squares:** A method to find the best-fitting line by minimizing the squared vertical distances between data points and the line.

- **P-value:** Determines if the relationship between variables is statistically significant; a \(p\)-value \(<0.05\) usually indicates a significant relationship.

- **Multicollinearity:** In multiple regression, this occurs when independent variables are highly correlated with each other, making it difficult to determine individual impact.
