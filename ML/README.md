# MACHINE LEARNING
Machine learning (ML) is a subset of artificial intelligence (AI) that develops algorithms enabling computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every rule.

## Key Aspects of Machine Learning:

- **Core Principle:** Instead of hard-coding instructions, machines are trained on large datasets to identify patterns and generalize to new, unseen data.
- **Types of Machine Learning:**
    - **Supervised Learning:** Algorithms are trained on labeled data to predict outcomes (e.g., classification, regression).
    - **Unsupervised Learning:** Algorithms analyze unlabeled data to find hidden structures or patterns (e.g., clustering).
    - **Reinforcement Learning:** Agents learn to make decisions through trial and error to maximize a reward signal.
- **Foundations:** Built on mathematics, statistics, and computer programming.
- **Process:** Includes defining business goals, data processing, model training, evaluation, and monitoring.
