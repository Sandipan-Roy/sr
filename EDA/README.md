# EXPLORATORY DATA ANALYSIS(EDA)
Exploratory Data Analysis (EDA) in Data Science is the critical initial process of analyzing, cleaning, and visualizing datasets to uncover underlying patterns, detect anomalies, test assumptions, and check data quality before building predictive models. It acts as a foundational step to understand data structure and relationships using statistical summaries and graphs

The purpose of this is to create a concise workbook covering advanced skills in using NumPy, Pandas, Matplotlib and Seaborn, uncovering insights, patterns, and relationships within the data.
