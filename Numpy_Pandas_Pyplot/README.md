# EDA (Exploratory Data Analysis)

## NUMPY, PANDAS AND MATPLOTLIB
A concise workbook covering foundational skills in using NumPy, Pandas and Matplotlib, the essential libraries for data manipulation in Python.
The aim is to develop foundational skills in using NumPy and Pandas, two essential libraries for data manipulation in Python. Here I've explored the basic capabilities of these libraries by performing various operations on numerical and tabular data, which helped me to gain hands-on experience with array operations, data handling, and preprocessing techniques necessary for data analysis and machine learning.
